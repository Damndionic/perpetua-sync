# Security

Perpetua Sync is trusted by the guild's officers to run on their PCs, so security problems matter more than anything
else here.

**Report a problem privately** with GitHub's "Report a vulnerability" button on this repository's Security tab, or
message the guild master on the Perpetua Discord. Please don't open a public issue for it.

What counts: anything that lets the app, the site's sync endpoints, or data from the site do more than the README says
(run code, read or write other files, reach other servers, use someone else's key).
